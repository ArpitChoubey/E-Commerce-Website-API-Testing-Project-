# 🔌 APIs Covered

The project validates the complete Shopping Cart lifecycle.

### 🟢 Refresh Cart

**GET**

Refreshes shopping cart fragments and synchronizes the latest cart information.

Endpoint:

```
GET /?wc-ajax=get_refreshed_fragments
```

Validated:

- Cart synchronization
- Response payload
- Session handling
- Performance

---

### 🟠 Add Product to Cart

**POST**

Adds selected products into the shopping cart.

Endpoint:

```
POST /?wc-ajax=add_to_cart
```

Validated:

- Valid product addition

- Invalid product IDs

- Quantity validation

- Duplicate additions

- Session management

---

### 🔵 Update Cart

**PUT**

Updates existing cart details.

Endpoint:

```
PUT /?wc-ajax=update_cart
```

Validated:

- Quantity updates

- Invalid quantities

- Empty cart handling

- Data consistency

---

### 🟡 Update Cart Item

**PATCH**

Updates specific cart items.

Endpoint:

```
PATCH /?wc-ajax=update_cart_item
```

Validated:

- Partial updates

- Existing items

- Invalid requests

---

### 🔴 Remove Product

**DELETE**

Removes products from the shopping cart.

Endpoint:

```
DELETE /?wc-ajax=remove_from_cart
```

Validated:

- Existing products

- Invalid items

- Empty cart

- Session cleanup
